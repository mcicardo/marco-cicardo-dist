# 🌸 Anime Web Page

Welcome to the **Anime Web Page** project! This is a simple, responsive web page designed to showcase anime content using modern HTML, CSS, and JavaScript. Ideal for anime fans, bloggers, or anyone who wants to create a sleek front-end experience with anime flair.

## 📂 Folder Structure

Only the files inside the `dist/` folder are deployed and used in the live version.
